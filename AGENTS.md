# skit

## Agent skills

Per-repo configuration for the `mattpocock/skills` engineering skills (`triage`, `to-spec`, `to-tickets`, `implement`, `tdd`, `code-review`, `domain-modeling`).

### Issue tracker

Plane project Skit (`SKIT-<n>`) in workspace `oklch`, via the REST API. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical roles, label strings unchanged (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), alongside the orthogonal `bug`/`enhancement` labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
